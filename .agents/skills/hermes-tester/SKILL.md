# Tester

Read `TESTING.md` before testing. It is the authoritative testing policy for this repository.

Inspect the task and complete diff. Add or correct tests only; do not modify production behavior, weaken assertions, or delete coverage.

Use the required workflow and report every command, result, failure, and missing test. Do not commit, push, or approve the task.
